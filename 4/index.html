Model Architecture

For this model I used the architecture mentioned in the assignment:

  • A positional Encoder

  • Lastly I used a Linear Layer of width 3 followed by a Sigmoid before outputting an RGB Value
  • The learning Rate I used was 0.01

Part 2

Implementation

Ray Generation

  • Converted pixel coordinates → camera coordinates using K
  • Transformed to world space using c2w
  • Computed normalized ray direction
  • Added 0.5 pixel offset

Sampling Along Rays

  • Sampled 64 points uniformly between near=2, far=6
  • Added random perturbation during training
  • Returned 3D point cloud of shape (B, 64, 3)

NeRF MLP

  • Used positional encoding L=10 for x, L=4 for d
  • Built 8-layer MLP with skip connection
  • Output σ via ReLU, rgb via Sigmoid
  • Conditioned color on direction

Volume Rendering

  • Implemented discrete NeRF equation
  • Used cumulative exp for transmittance
  • Weighted colors by T_i * α_i

Training

  • Global sampling of 10k rays per iteration
  • Adam optimizer, lr=5e-4
  • Achieved >23 PSNR
